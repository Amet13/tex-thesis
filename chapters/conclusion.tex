\anonsection{Conclusion}

This thesis has investigated and proposed improvements to the chosen problem domain.

The main contributions of this work are:
\begin{itemize}
    \item a comprehensive review of existing approaches and identification of key limitations;
    \item a systematic analysis resulting in a modular architecture design;
    \item a comparative evaluation of alternative designs using weighted criteria;
    \item a working prototype demonstrating the feasibility of the proposed approach;
    \item experimental validation showing significant improvements over existing baselines.
\end{itemize}

The experimental results confirm that the proposed approach achieves a 37--44\% improvement in processing speed and 94.2\% accuracy, outperforming both baseline implementations.

Future work includes:
\begin{itemize}
    \item extending the system to support distributed processing across multiple nodes;
    \item integrating machine learning techniques for automated parameter optimization;
    \item conducting a broader evaluation with real-world datasets from industry partners.
\end{itemize}

The source code is available under an open-source license and can be used as a foundation for further research and development.
