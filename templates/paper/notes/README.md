# notes/

Raw material for the paper: the research question, experiment logs, result
tables, reading notes with DOIs, reviewer comments, venue instructions.

Nothing here is compiled into the PDF. Keep the facts *you* know in this
folder so that you, or an AI agent working on the repository, can write from
them without inventing anything. An agent that needs a fact it cannot find
here or in a cited source should ask you rather than guess.

Suggested files:

- `question.md`: the one question the paper answers, and the claimed answer
- `experiments.md`: what was run, settings, seeds, where results are stored
- `sources.md`: papers read, with DOI or arXiv id and a one-line takeaway
- `venue.md`: page limit, anonymity and AI-disclosure rules of the target venue
