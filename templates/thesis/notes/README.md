# notes/

Raw material for the thesis: meeting notes, reading notes, experiment logs,
outlines, data descriptions, reviewer comments.

Nothing in this folder is compiled into the PDF. It is the place to keep
facts *you* know, so that you (or an AI agent working on this repository)
can turn them into text without inventing anything. When an agent writes a
section, point it at the relevant note; when it needs a fact it cannot find
here or in the sources, it should ask you instead of guessing.

Suggested files:

- `outline.md`: chapter plan and the argument of each section
- `sources.md`: papers you have read, with DOIs and one-line takeaways
- `experiments.md`: what was run, when, with which settings, where results live
- `advisor.md`: feedback and decisions from supervision meetings
