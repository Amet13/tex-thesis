\section{Problem statement}\label{sec:problem}

The primary goal of this thesis is to investigate and improve the effectiveness of the chosen approach in the selected domain.
To achieve this goal, it is necessary to develop a structured methodology, implement a prototype, and conduct experimental validation.

The following tasks must be completed:
\begin{itemize}
  \item review existing approaches and identify their limitations;
  \item analyze the requirements and constraints of the target domain;
  \item design and implement a prototype system;
  \item evaluate the proposed solution through experiments;
  \item compare the results with existing alternatives.
\end{itemize}

The input data for this research includes:
\begin{itemize}
  \item a dataset of sample measurements;
  \item configuration parameters for the experimental setup;
  \item baseline metrics from existing solutions.
\end{itemize}

The expected output includes:
\begin{itemize}
  \item a prototype implementation of the proposed approach;
  \item experimental results demonstrating its effectiveness;
  \item a comparative analysis with existing methods.
\end{itemize}

The hardware requirements for running the experiments are:
\begin{itemize}
  \item a processor with multi-core support;
  \item minimum \qty{8}{\giga\byte} of RAM, recommended \qty{16}{\giga\byte} or more;
  \item at least \qty{20}{\giga\byte} of free disk space (SSD);
  \item Ubuntu 24.04 or later, macOS, or Windows with WSL.
\end{itemize}

This problem is also examined from the perspective of system analysis and comparative design evaluation.
