\section{Results analysis}

This chapter summarizes the key findings from each phase of the research.

\textbf{Literature review.}
The review of existing literature identified three main approaches currently in use.
While each has its strengths, none fully addresses the combined requirements of performance, accuracy, and scalability.

\textbf{System analysis.}
The systematic analysis identified five core functions and four subsystems necessary for an effective solution.
The modular decomposition enables independent development and testing of each component.

\textbf{Design evaluation.}
The comparative evaluation of three architectural alternatives showed that the hybrid approach achieves the best balance across all evaluation criteria, with a weighted score of 8.30 out of 10.

\textbf{Implementation.}
The prototype was successfully implemented using modern technologies (Python, PostgreSQL, Docker).
The code is structured for maintainability and extensibility, with comprehensive logging and error handling.

\textbf{Experimental evaluation.}
Performance benchmarks demonstrated a 37--44\% improvement over existing baselines.
The system achieved 94.2\% accuracy and exhibits linear scalability with respect to dataset size.
